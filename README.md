# 🏋️‍♂️ FitChain - Decentralized Fitness Tracker

FitChain is a Web3 fitness tracking application that records workouts on the blockchain, tracks streaks, and awards NFT achievement badges.

## 🚀 Features

- **Blockchain Workout Logging**: Immutable fitness history on Ethereum
- **Streak Tracking**: Build consecutive day streaks
- **NFT Badges**: Earn achievement badges as NFTs
- **Leaderboard**: Compete with other users
- **Web3 Composability**: Integrate with other DeFi protocols

## 🛠️ Tech Stack

- **Frontend**: React, Vite, Tailwind CSS
- **Web3**: Wagmi, RainbowKit, Ethers.js
- **Blockchain**: Ethereum (Sepolia Testnet)
- **Smart Contracts**: Solidity, Hardhat

## 🏃‍♂️ Getting Started

### Prerequisites

- Node.js 18+
- MetaMask wallet
- Sepolia testnet ETH

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/fitchain.git
cd fitchain
```

2. Install dependencies:
```bash
cd client
npm install
```

3. Set up environment variables:
```bash
cp .env.example .env.local
# Add your contract address and API keys
```

4. Run the development server:
```bash
npm run dev
```
